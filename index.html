The Catch

The Catch is an animated YouTube channel of "What if…" stories: youtube.com/@thecatchtales.

Catch retention

Catch retention is a private script the channel's author runs on his own computer. It reads the audience retention of the channel's own videos from the YouTube Analytics API and lines it up with the chapters and lines of each video, so the author can see where viewers leave.

It is not a public service: only the channel owner signs in, with read-only access to the channel's analytics.
