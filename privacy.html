Privacy Policy — Catch retention

Last updated: 8 November 2026.

Catch retention is a private script used by the author of the YouTube channel The Catch to study audience retention of his own videos.

What data it accesses

With the channel owner's permission (Google OAuth scope yt-analytics.readonly), the script reads aggregated YouTube Analytics reports for the owner's channel: audience retention by video position, views and average view duration. It cannot change anything on YouTube and does not access any other Google data.

How the data is used and stored

Reports are saved only on the channel owner's own computer and used to write retention reports for the owner. The sign-in token is stored in the owner's home folder on that computer. The data is not sold, not shared with anyone and not sent to any third party, except the owner's own private Telegram chat with a short weekly summary.

The script does not collect any information about viewers as individuals: YouTube Analytics only provides aggregated numbers.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally saved reports can be deleted by the owner at any time.
